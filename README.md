# Atrium technical report

Technical documentation for [Atrium](https://atrium.earth), a digital sculpture museum.

**[Read the report (PDF)](atrium-technical-report.pdf)** · [Download the PDF](https://raw.githubusercontent.com/never-nude/atrium-technical-report/main/atrium-technical-report.pdf)

## About the report

Written by **OpenAI Codex (AI)** at the project creator's request, from repository inspection and recorded project checks. This is AI-written documentation, not a personal account by the creator or an independent audit.

The 14-page report covers the website architecture, 3D model storage and delivery, AR/VR implementation, physical dimensions and chosen display sizes, lighting, and testing limits. An evidence index is embedded in the PDF.

**Snapshot:** 13 September 2026. [Implementation source at the documented revision](https://github.com/never-nude/atrium.earth/tree/541669e476adc7e2747b729cc73fd1efe0194b58).

The creator has **not personally tested VR in a headset**. Not every work has verified physical dimensions, and browser/export checks do not establish real-device accuracy or outdoor appearance.

This repository contains the report. [Website source code](https://github.com/never-nude/atrium.earth) is maintained separately.
